# MetalPro ERP — приватная галерея экранов

Этот отдельный приватный Git содержит только скриншоты реального интерфейса ERP и их описание. Репозиторий с исходным кодом MetalPro тоже закрытый: [MetalPro](https://github.com/kirillbavin-svg/MetalPro). Программный код, рабочая база, конфигурация и пароли в галерею не включаются.

## Скриншоты

[Открыть полную галерею](screenshots/index.md) — экраны основных разделов, форм, вкладок и отчётов. Кадры сняты в Google Chrome. Имена сотрудников, клиентов и проектов скрыты, другие значения оставлены видимыми.

Пропуски в нумерации связаны с исключёнными адресами, которые возвращали JSON/API или ошибку вместо пользовательского экрана. Некоторые разделы показывают пустое состояние, если данных для него в текущей учётной записи нет. Закрытый кабинет заказчика представлен экраном входа; личная учётная запись заказчика не использовалась.
