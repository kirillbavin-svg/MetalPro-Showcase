## Правила галереи

- Снимать реальные экраны ERP в Google Chrome, по одному файлу PNG на экран.
- Скрывать имена сотрудников и заказчиков; остальное содержимое оставлять видимым.
- Использовать нейтральные имена файлов без названий клиентов и проектов.
- Удалённый репозиторий приватный; исходный код MetalPro и рабочая база сюда не отправляются.
- Не добавлять исходный код, пароли, файл настроек, базу данных, журналы или отдельные файлы заказчиков.
